Nota sobre o funcionamento deste modelo. Não substitui uma política de privacidade de uma empresa real.

1. Natureza do site

A Radio FIDC é uma empresa fictícia utilizada para demonstrar um site institucional. Não existe contratação ou atendimento financeiro neste modelo.

2. Formulários demonstrativos

Os campos de contato e de acesso do cliente são validados no navegador. O JavaScript deste projeto não transmite os valores preenchidos nem os grava em cookies, localStorage ou banco de dados. Não utilize dados pessoais reais. O navegador pode oferecer seu próprio recurso de preenchimento automático.

3. Recursos e hospedagem

Os recursos visuais, estilos e scripts são locais. O projeto não inclui ferramentas de publicidade, análise de audiência ou fontes remotas. O provedor que hospedar o site pode manter registros de acesso conforme suas próprias configurações.

4. Links externos

A área do cliente poderá direcionar para um sistema separado quando um endereço real for configurado. Esse sistema deverá apresentar suas próprias informações sobre dados e privacidade.

5. Antes de publicar uma empresa real

Substitua esta nota por um documento que descreva os tratamentos efetivos, os canais de contato e os serviços utilizados pela empresa. Revise também qualquer formulário e integração adicionados.
