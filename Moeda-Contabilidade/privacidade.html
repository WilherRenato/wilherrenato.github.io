Nota demonstrativa sobre o funcionamento deste projeto, para revisão antes de uso comercial.

1. Natureza do modelo

A Moeda Contabilidade é uma empresa fictícia. Este site não presta atendimento contábil real.

2. Contato e área do cliente

Os formulários são validados no navegador. O código deste projeto não envia os dados nem grava credenciais em cookies, localStorage ou banco de dados. Não utilize informações reais nesta apresentação. O navegador pode oferecer seu próprio preenchimento automático.

3. Recursos e hospedagem

Imagens, estilos e scripts são locais. Não há ferramentas de analytics ou publicidade implementadas. A hospedagem pode manter registros de acesso de acordo com sua configuração.

4. Integração futura

Uma autenticação real deve utilizar uma rota apropriada, comunicação HTTPS e validações no servidor. A política deve refletir os serviços e os tratamentos de dados efetivamente utilizados.

5. Personalização

Substitua os dados institucionais, os canais de atendimento e esta nota antes da publicação de um escritório real. Os conteúdos devem ser revisados pelo responsável do escritório.
